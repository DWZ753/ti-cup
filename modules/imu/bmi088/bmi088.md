# BMI088 六轴传感器驱动

## 概述

Bosch BMI088 六轴 IMU 传感器（加速度计 + 陀螺仪）的 SPI 驱动。支持双片选（CS）独立访问加速度计和陀螺仪，提供原始数据读取（m/s² 和 rad/s 单位输出）和芯片 ID 验证。

## 硬件接口

| 信号 | 引脚 | 说明 |
|------|------|------|
| SPI_SCK | PB10 | SPI 时钟 |
| SPI_MOSI | PB11 | 主机→传感器 |
| SPI_MISO | PB12 | 传感器→主机 |
| ACCEL_CS | PB13 | 加速度计片选（低有效） |
| GYRO_CS | PB15 | 陀螺仪片选（低有效） |

## SPI 协议

- **写操作**：SPI 寄存器地址最高位 = 0（`reg & 0x7F`）
- **读操作**：SPI 寄存器地址最高位 = 1（`reg | 0x80`）
- 加速度计读取前需发送一个 dummy byte（`0xFF`）

## 传感器规格

### 加速度计 (BMI088 Accelerometer)

| 参数 | 值 |
|------|-----|
| 芯片 ID | 0x1E |
| 量程 | ±6g |
| 灵敏度 | 0.001795 m/s²/LSB |
| 分辨率 | 16 位 |
| 数据寄存器 | 0x12~0x17（X_LSB, X_MSB, Y_LSB, Y_MSB, Z_LSB, Z_MSB） |

### 陀螺仪 (BMI088 Gyroscope)

| 参数 | 值 |
|------|-----|
| 芯片 ID | 0x0F |
| 量程 | ±2000°/s |
| 灵敏度 | 0.001065264436 rad/s/LSB |
| 分辨率 | 16 位 |
| 数据寄存器 | 0x02~0x07（RATE_X_LSB ~ RATE_Z_MSB） |

## 寄存器地址

```c
// 加速度计
#define BMI088_REG_ACC_CHIP_ID      0x00   // 芯片 ID
#define BMI088_REG_ACC_X_LSB        0x12   // X 轴低字节
#define BMI088_REG_ACC_PWR_CTRL     0x7D   // 电源控制
#define BMI088_REG_ACC_SOFTRESET    0x7E   // 软复位

// 陀螺仪
#define BMI088_REG_GYR_CHIP_ID      0x00   // 芯片 ID
#define BMI088_REG_GYR_SOFTRESET    0x14   // 软复位

// 软复位命令值
#define BMI088_SOFTRESET_VALUE      0xB6
```

## API

| 函数 | 说明 |
|------|------|
| `BMI088_Init(SPI_Handle *spi)` | 初始化传感器（加速度计和陀螺仪分别软复位），返回 0 表示成功 |
| `BMI088_ReadAccel(float accel[3])` | 读取加速度计三轴数据，输出 `[x, y, z]` m/s² |
| `BMI088_ReadGyro(float gyro[3])` | 读取陀螺仪三轴数据（含 Chip ID 校验），输出 `[x, y, z]` rad/s |
| `BMI088_ReadAccelID()` | 读取加速度计 Chip ID（应为 0x1E） |
| `BMI088_ReadGyroID()` | 读取陀螺仪 Chip ID（应为 0x0F） |
| `BMI088_ReadRawBytes(reg, buf, len, cs_sel)` | 裸读寄存器（调试用），`cs_sel`: 0=加速度计, 1=陀螺仪 |

## 数据读取流程

### 加速度计

```
1. CS_ACCEL 拉低
2. 发送读命令：0x12 | 0x80
3. 发送 dummy byte（0xFF）
4. 连续读取 6 字节（X_LSB, X_MSB, Y_LSB, Y_MSB, Z_LSB, Z_MSB）
5. CS_ACCEL 拉高
6. 解析：raw = (MSB << 8) | LSB，value = raw × 0.001795 (m/s²)
```

### 陀螺仪

```
1. CS_GYRO 拉低
2. 发送读命令：0x00 | 0x80（从 Chip ID 寄存器开始读取）
3. 连续读取 8 字节
   - buf[0]: Chip ID（校验是否为 0x0F）
   - buf[2~7]: 角速度数据（RATE_X_LSB ~ RATE_Z_MSB）
4. CS_GYRO 拉高
5. 若 Chip ID 正确，解析：raw = (MSB << 8) | LSB，value = raw × 0.001065 (rad/s)
```

## 使用示例

```c
#include "bmi088.h"

SPI_Handle *spi = SPI_Init(&(SPI_Config){.spi = SPI0});
BMI088_Init(spi);

// 验证芯片
uint8_t acc_id = BMI088_ReadAccelID();  // 应为 0x1E
uint8_t gyr_id = BMI088_ReadGyroID();   // 应为 0x0F

// 读取数据
float accel[3], gyro[3];
BMI088_ReadAccel(accel);
BMI088_ReadGyro(gyro);
// accel = [ax, ay, az] m/s²
// gyro  = [gx, gy, gz] rad/s
```

## 注意事项

- 陀螺仪读取前会校验 Chip ID，若校验失败则 `gyro[]` 保持上一次的值不变
- 加速度计软复位后需等待 10ms，上电后需等待 5ms
- 陀螺仪软复位后需等待 30ms
- 当前量程固定为加速度计 ±6g、陀螺仪 ±2000°/s，如需更改量程，需修改 `BMI088_ACCEL_RANGE` 宏并重新计算灵敏度系数
