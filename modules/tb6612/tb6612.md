# TB6612 电机驱动模块

## 概述

TB6612FNG 双 H 桥电机驱动芯片的底层驱动模块。提供两个电机通道（A/B）的**正转、反转、制动、停止**四种基本操作，通过 GPIO 控制方向 + PWM 控制速度。

> **注意：** 本模块是底层驱动，通常不直接使用。上层应用应使用 [Motor 电机模块](../motor/motor.md)，它封装了 TB6612 + 编码器测速，提供统一的线速度接口。

## 文件

| 文件 | 说明 |
|------|------|
| `tb6612.h` | 模块头文件，硬件映射宏与 API 声明 |
| `tb6612.c` | 模块实现 |

## 硬件控制逻辑

TB6612 每个 H 桥通道有 3 个控制引脚：

| 控制模式 | IN1 | IN2 | PWM |
|----------|-----|-----|-----|
| 正转 (Forward) | H | L | PWM 占空比 |
| 反转 (Backward) | L | H | PWM 占空比 |
| 制动 (Brake) | H | H | 任意 |
| 停止/滑行 (Stop) | L | L | 任意 |

- **制动**：两输入端同时置高 → 电机两端短接 → 快速停止
- **停止**：两输入端同时置低 → 电机断开 → 惯性滑行

## 宏定义

```c
#define TB6612_PWM_TIMER           PWM_MOTOR_INST           // PWM 定时器实例
#define TB6612_PWM_A_PIN           GPIO_PWM_MOTOR_C0_IDX    // A 通道 PWM 通道索引
#define TB6612_PWM_B_PIN           GPIO_PWM_MOTOR_C1_IDX    // B 通道 PWM 通道索引
#define TB6612_GPIO_PORT           GPIO_PWM_MOTOR_C0_PORT   // 控制 GPIO 端口
#define TB6612_GPIO_AIN1_PIN       GPIO_MOTORs_GPIO_MOTOR1_IN1_PIN  // A通道IN1
#define TB6612_GPIO_AIN2_PIN       GPIO_MOTORs_GPIO_MOTOR1_IN2_PIN  // A通道IN2
#define TB6612_GPIO_BIN1_PIN       GPIO_MOTORs_GPIO_MOTOR2_IN1_PIN  // B通道IN1
#define TB6612_GPIO_BIN2_PIN       GPIO_MOTORs_GPIO_MOTOR2_IN2_PIN  // B通道IN2
#define TB6612_PWM_PERIOD_COUNT    10000                    // PWM 周期计数值（决定最高分辨率）
```

PWM 占空比范围为 `[0, TB6612_PWM_PERIOD_COUNT]`，值越大转速越快。

## API

### `void TB6612_Init(void)`

初始化 TB6612 模块，启动 PWM 定时器。

> 此函数由 `Board_Init()` 自动调用。

### `uint32_t TB6612_LimitPWM(uint32_t period_count)`

将 PWM 占空比限制在有效范围 `[0, TB6612_PWM_PERIOD_COUNT]` 内。

### A 通道（电机 1）

| 函数 | 说明 |
|------|------|
| `TB6612_A_Forward(uint32_t duty)` | A 电机正转 |
| `TB6612_A_Backward(uint32_t duty)` | A 电机反转 |
| `TB6612_A_Brake(void)` | A 电机制动（IN1=IN2=H） |
| `TB6612_A_Stop(void)` | A 电机滑行停止（IN1=IN2=L） |

### B 通道（电机 2）

| 函数 | 说明 |
|------|------|
| `TB6612_B_Forward(uint32_t duty)` | B 电机正转 |
| `TB6612_B_Backward(uint32_t duty)` | B 电机反转 |
| `TB6612_B_Brake(void)` | B 电机制动（IN1=IN2=H） |
| `TB6612_B_Stop(void)` | B 电机滑行停止（IN1=IN2=L） |

## 依赖

- `ti_msp_dl_config.h`（提供 GPIO 和 PWM 外设驱动）

## 使用示例（直接操作）

```c
#include "tb6612.h"

// 初始化
TB6612_Init();

// A 电机正转，50% 占空比
TB6612_A_Forward(5000);

// A 电机反转，30% 占空比
TB6612_A_Backward(3000);

// A 电机制动（快速停止）
TB6612_A_Brake();

// A 电机滑行停止
TB6612_A_Stop();

// 同步控制两路电机
TB6612_A_Forward(6000);
TB6612_B_Forward(6000);
```

## 注意事项

- 本模块仅做简单限幅（`TB6612_LimitPWM`），不处理电机死区（最低启动占空比）。上层 `Motor_SetSpeed()` 通过 `MOTOR_MIN_DUTY` 处理死区
