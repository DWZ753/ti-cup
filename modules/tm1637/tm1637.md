# TM1637 四位数码管模块

## 概述

TM1637 四位数码管驱动模块，通过两线自定义串行协议（CLK + DIO）通信。支持显示整数（-999~9999）、时间格式（MM:SS）、自定义段码，亮度可调。

自包含初始化，直接使用 SysConfig 生成的 GPIO 宏，不依赖 BSP 抽象层。

## 文件

| 文件 | 说明 |
|------|------|
| `tm1637.h` | 模块头文件，API 声明 |
| `tm1637.c` | 模块实现 |

## 硬件说明

| 参数 | 说明 |
|------|------|
| 接口 | 两线串行（CLK + DIO），类似 I2C 但非标准 I2C |
| 芯片 | TM1637 |
| 供电 | 5V（DIO/CLK 耐压 5V，3.3V MCU 可直驱） |

GPIO 引脚由 SysConfig 的 `GPIO_TM1637` 实例配置（PB3=CLK, PB25=DIO）。

## API

### 初始化与显示控制

#### `void TM1637_Init(void)`

自包含初始化。内部完成：
1. 引脚置 HIGH（空闲态）
2. 发送显示关命令
3. 清屏

> 需在 `SYSCFG_DL_init()` 之后调用。

#### `void TM1637_Clear(void)`

清屏（四位全灭）。

#### `void TM1637_SetBrightness(uint8_t level)`

设置亮度，不重写当前显示的段码。`level` = 0（最暗）~ 7（最亮）。

### 内容显示

#### `void TM1637_DisplayNum(int16_t num, bool leading_zero)`

显示整数。

| 参数 | 说明 |
|------|------|
| `num` | 要显示的数字，范围 -999 ~ 9999 |
| `leading_zero` | `true` = 前导零填充（`0042`），`false` = 前导消隐（`  42`） |

#### `void TM1637_DisplayTime(uint8_t min, uint8_t sec, bool colon_on)`

显示时间格式 MM:SS。

| 参数 | 说明 |
|------|------|
| `min` | 分钟，0 ~ 99 |
| `sec` | 秒，0 ~ 59 |
| `colon_on` | `true` = 冒号点亮，`false` = 熄灭 |

#### `void TM1637_DisplaySegments(const uint8_t segs[4])`

直接写 4 字节段码（底层接口）。`segs[0]` = 最左位。

### 工具函数

#### `uint8_t TM1637_EncodeDigit(uint8_t digit)`

数字 0~9 转 7 段码。超范围返回 0。

## 段码编码

```
   A
F     B
   G
E     C
   D    •DP

bit:  7   6   5   4   3   2   1   0
      DP   G   F   E   D   C   B   A
```

| 字符 | 段码 | 字符 | 段码 |
|------|------|------|------|
| 0 | `0x3F` | 5 | `0x6D` |
| 1 | `0x06` | 6 | `0x7D` |
| 2 | `0x5B` | 7 | `0x07` |
| 3 | `0x4F` | 8 | `0x7F` |
| 4 | `0x66` | 9 | `0x6F` |
| `-` | `0x40` | 全灭 | `0x00` |

- **bit7（DP）**：在 `DisplayTime` 中，第二位（`segs[1]`）的 DP 用作时钟冒号。

## 依赖

- `ti_msp_dl_config.h`（SysConfig 生成的 `GPIO_TM1637_*` 宏）
- `delay_cycles()`（编译器内建）

## 使用示例

```c
#include "tm1637.h"

// 初始化
TM1637_Init();
TM1637_SetBrightness(5);

// 显示整数
TM1637_DisplayNum(42, false);       // "  42"
TM1637_DisplayNum(42, true);        // "0042"
TM1637_DisplayNum(-123, false);     // "-123"

// 显示时间
TM1637_DisplayTime(12, 59, true);   // "12:59"（冒号亮）
TM1637_DisplayTime(12, 59, false);  // "12 59"（冒号灭）

// 自定义段码：显示 "HELP"
uint8_t segs[4] = {0x76, 0x79, 0x38, 0x73};
TM1637_DisplaySegments(segs);

// 非阻塞计数
uint32_t last = 0;
uint16_t cnt  = 0;
while (1)
{
    uint32_t now = Board_GetTickMs();
    if (now - last >= 200)
    {
        last = now;
        TM1637_DisplayNum((int16_t)cnt, true);
        cnt++;
        if (cnt > 9999) cnt = 0;
    }
}
```
