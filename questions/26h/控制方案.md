# 26H 题：车载平衡滚球运动控制系统 — 控制方案

## 一、题目概述

| 要素 | 内容 |
|------|------|
| 赛道 | 椭圆环线（黑线 1.8cm 宽），AB=CD=1.5m 直道，BC=DA 为 R=0.5m 半圆 |
| 核心机构 | 25cm PPR 水管（外径 2cm，内壁光滑）作为**摆杆**，内装 ~1cm 钢球 |
| 控制目标 | 通过**摆杆角度控制机构**让球稳定在摆杆中的指定位置 |
| 图传要求 | 摄像头固定在摆杆上方 → 实时推流到外部 PAD/笔记本，需存储+回放 |

**关键约束：**
- 车体 ≤35×25cm，电池供电，禁止遥控
- 摆杆中心 O 距车平面高 5cm
- 摆杆内壁光滑，不得有任何摩擦处理
- 摄像头装摆杆上方，随摆杆运动
- 车上显示装置 ≤2 英寸，图传接收端可用 PAD/笔记本

## 四、控制系统架构

```
小车端：
├── MSPM0G3507（主控）
│   ├── 灰度循迹 → 沿黑线行驶
│   ├── 直流电机 + 舵机 → 小车运动
│   ├── ZDT步进电机 → 摆杆角度控制（balance 模块）
│   ├── 编码器 → 里程计/速度
│   └── UART → 与树莓派通信
│
├── 树莓派（视觉+图传）
│   ├── 摄像头 → 检测球在摆杆中的位置
│   ├── WiFi/网络 → 图传推流到PAD
│   └── UART → 发送球位置给MSPM0

显示端：
└── PAD/笔记本
    └── 接收图传流 + 显示 + 存储 + 回放
```

## 五、关键控制策略

### 5.1 循迹（MSPM0）

用 `tracking` + `motor` + `servo` 模块。需要适配：
- 速度闭环控制（编码器反馈），保证匀速
- 过弯减速（半圆 R=0.5m，需要前轮打角 + 降速）
- A 点停车检测（黑色横线识别）

### 5.2 摆杆控制（MSPM0）— 球-梁系统

```
目标球位置(mm) ─→ [位置PID] ─→ 目标摆杆角度(°) ─→ ZDT步进电机
       ▲                                          │
       │                                          ▼
       └──── 实际球位置(mm) ◄── 树莓派摄像头 ◄── 摆杆物理
```

- 外环（位置环）：球位置 → 摆杆目标角度
- 内环（角度环）：ZDT 闭环步进电机直驱
- ZDT 3200 pulse/rev，精度足够（0.1125°/pulse）

### 5.3 球位置检测（树莓派）

- 摄像头俯视摆杆 → 颜色阈值/轮廓检测球 → 映射 mm
- UART 发给 MSPM0：`int16_t ball_pos_mm`（相对于 O 点）

### 5.4 行驶中惯性补偿

- 直道加减速 → 前馈倾角
- 弯道离心力 → 内侧倾角补偿
- 前馈 + PID 反馈结合
