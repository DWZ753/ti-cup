# 2026 智能物流搬运 — 通信协议设计

## 系统架构

```
┌─────────────┐   无线(UART)    ┌─────────────┐
│ 计分显示装置  │ ←───────────→ │  MSPM0 小车   │
│  (display)   │   COBS帧       │   (car)      │
└─────────────┘                └──┬────┬────┬─┘
                                  │    │    │
                           有线UART   GPIO  GPIO
                                  │    │    │
                           ┌──────┘    │    └─── 前轮舵机
                           │           └─── 后轮电机(TB6612 差速)
                    ┌──────┴──────┐
                    │   树莓派     │
                    │ USB摄像头    │
                    │ 视觉识别     │
                    │ 决策控制     │
                    └─────────────┘
```

**两条通信链路：**
- Display ↔ MSPM0：无线，走 COBS 协议（命令码 0x01~0x03, 0x10~0x14）
- Pi ↔ MSPM0：有线 UART，走 COBS 协议（命令码 0x20~0x3F）

---

## 传输层

使用 `modules/protocol/`（COBS + XOR 校验），单帧最大载荷 64 字节。

帧格式：`[COBS(cmd + payload + checksum)] [0x00]`

## 命令表

### 计分显示装置 → 小车

| 命令 | 值 | Payload | 说明 |
|------|-----|---------|------|
| CMD_START | 0x01 | 无 | 启动搬运任务 |
| CMD_STOP | 0x02 | 无 | 正常停止 |
| CMD_EMERGENCY | 0x03 | 无 | 急停 |

### 小车 → 计分显示装置

| 命令 | 值 | Payload | 说明 |
|------|-----|---------|------|
| CMD_COUNT | 0x10 | uint8 | 已搬运数量 |
| CMD_WEIGHT | 0x11 | uint16 (大端) | 重量变化(g) |
| CMD_STATUS | 0x12 | uint8 | 系统状态 |
| CMD_TIME | 0x13 | uint16 (大端) | 单球耗时(s) |
| CMD_COMPLETE | 0x14 | 无 | 全部完成 |

### 树莓派 → 小车

| 命令 | 值 | Payload | 说明 |
|------|-----|---------|------|
| CMD_GUIDE | 0x20 | speed(int8), diff(int8) | 锁定引导 |
| CMD_STOP | 0x21 | 无 | 立即停车 |
| CMD_MAGNET_ON | 0x22 | 无 | 电磁铁吸合 |
| CMD_MAGNET_OFF | 0x23 | 无 | 电磁铁释放 |
| CMD_GIMBAL | 0x24 | angle_deg(int16, 大端) | 云台 pitch 角度 |
| CMD_RESUME_LINE | 0x2F | 无 | 回到灰度循迹 |

### 小车 → 树莓派

| 命令 | 值 | Payload | 说明 |
|------|-----|---------|------|
| CMD_GIMBAL_OK | 0x30 | 无 | 云台已到位 |
| CMD_FAULT | 0x3F | error_code(uint8) | 故障上报 |

### 故障码

| 值 | 含义 |
|-----|------|
| 1 | GUIDED 模式 200ms 无指令，已自动停车 |
| 2 | 云台过流保护触发 |
| 3 | 云台堵转 |

## MSPM0 模式状态机

```
MODE_LINE_FOLLOW  ←──────── CMD_RESUME_LINE ──────────┐
  │  灰度 PID 循迹自治                                    │
  │  Pi 指令被忽略（除了 RESUME_LINE）                    │
  │                                                     │
  │  Pi 发 CMD_GUIDE / CMD_STOP / CMD_GIMBAL 等           │
  ▼                                                     │
MODE_GUIDED                                              │
  │  后轮差速由 Pi 控制                                    │
  │  前轮舵机回中                                         │
  │  200ms 无 Pi 指令 → 自动停车 + 上报 CMD_FAULT(1)      │
  │  云台/电磁铁指令独立响应                               │
  │                                                     │
  │  Pi 发 CMD_STOP → 停车但留在 GUIDED 模式               │
  └─────────────────────────────────────────────────────┘
```

## Pi 侧视觉确认与异常处理

### 锁定确认：连续 5 帧

```
帧1: 检测到候选球 → 标记候选
帧2~5: 同一区域持续检测 → 确认锁定 → 开始发 CMD_GUIDE
期间任何一帧丢失 → 放弃候选，继续搜索
```

### 丢锁检测：连续 3 帧

```
正在 CMD_GUIDE 引导中
连续 3 帧看不到球 → 丢锁
  → 发 CMD_STOP（车停下）
  → 本地尝试重新检测（用云台微调扫描）
  → 2 秒内恢复 → 继续 CMD_GUIDE
  → 2 秒内未恢复 → 发 CMD_GUIDE(speed=小值, diff=0) 慢速前进重新搜索
```

### 接近超时

```
开始 CMD_GUIDE 后计时
超过 3 秒球的大小（距离）没有显著变化
  → 可能是误检或球不可达
  → 发 CMD_STOP → 放弃 → 重新搜索下一个球
```

### MSPM0 保底：200ms 看门狗

```
GUIDED 模式下，距上次收到 Pi 任何帧超过 200ms
  → 自动停车（Motor_Stop）
  → 向 Pi 上报 CMD_FAULT(1)
  → 等 Pi 恢复通信
```

## 捡球完整流程

```
1. 循迹到达散布区入口
   MSPM0: MODE_LINE_FOLLOW，灰度循迹
   Pi:    旁观，不干预

2. 进入散布区
   Pi 发 CMD_GUIDE(speed=30, diff=0) → MSPM0 进入 MODE_GUIDED
   车脱离循迹线，Pi 接管控制

3. 搜索钢球
   Pi 控制车速 + 云台扫描
   检测到球 → 5 帧确认 → 锁定

4. 接近钢球
   Pi 持续发 CMD_GUIDE(speed, diff)
   speed/diff 由球在画面中的位置计算：
     - 球偏左 → diff 负（左转修正）
     - 球偏下 → speed 增大
     - 球越大 → 越近 → speed 减小（防止冲过头）

5. 吸取
   球足够近 → CMD_STOP → CMD_GIMBAL(机械臂下压) → CMD_MAGNET_ON
   等待 → CMD_GIMBAL(抬起) → 完成

6. 返回循迹线
   Pi 发 CMD_GUIDE 引导车回到黑线附近
   → 灰度传感器检测到线 → Pi 发 CMD_RESUME_LINE
   → MSPM0 回到 MODE_LINE_FOLLOW 自治循迹

7. 循迹去分拣轨道
   MSPM0 灰度循迹 → 到达轨道入口
   → CMD_GIMBAL(下压) → CMD_MAGNET_OFF → 释放
```

## 云台安全

- 上电归零：硬停回零，机械臂碰地面自动停止
- 角度上限：软件钳位，防止抬头过高扯断线缆
- 过流保护：ZDT 驱动板 OCP，800mA 触发
- 紧急停止：Gimbal_Stop() 立即停转
